# Colors

Sourced from `/DESIGN.md` §2 "Color Palette & Roles" and §9 "Quick color
reference". Every swatch below reads live from the CSS variables defined
in `app/globals.css` — if DESIGN.md and globals.css ever disagree, this
page diffs.

> **Reserve strong accent saturation for primary actions, focus indicators,
> and active states.** Use `--primary-soft` for selected backgrounds,
> active pane highlights, hover badges. Use warm surface treatment
> (`--bg-toolbar`) for featured CTA areas.

## Light / dark reference values

Per `/DESIGN.md` §9 (Quick color reference). These are the concrete
values each semantic token resolves to; the live swatches above track
whichever theme is currently active via the toolbar.

| Purpose | Light | Dark |
|---------|-------|------|
| Background | `#FFFFFF` | `#0A0A0A` |
| Surface | `#F3F7FA` | `#21282D` |
| Toolbar surface | `rgba(246,246,246,0.82)` | `rgba(38,38,38,0.85)` |
| Text | `#090D10` | `#FFFFFF` |
| Text secondary | `#3C464D` | `#CBD1D6` |
| Text muted | `#7E8991` | `#7E8991` |
| Accent | `#7B3FB8` | `#9E64D4` |
| Accent soft | `rgba(123,63,184,0.08)` | `rgba(158,100,212,0.14)` |
| Border | `rgba(0,0,0,0.05)` | `rgba(255,255,255,0.20)` |
| Border subtle | `rgba(0,0,0,0.06)` | `rgba(255,255,255,0.06)` |

## Do / don't

- **Do** use `--primary-soft` for selected-item backgrounds and active pane highlights.
- **Do** preserve panel/surface hierarchy through tone and border contrast before reaching for shadow.
- **Don't** introduce new chroma families without an explicit product decision.
- **Don't** raise accent saturation for ambient decoration.
- **Don't** reach for foundational palette tokens (`--purple-400`, `--greyscale-700`) inside components — compose a semantic token instead.
