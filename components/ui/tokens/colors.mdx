# Colors

Sourced from `/DESIGN.md` §2 "Color Palette & Roles" and §9 "Quick color
reference". Every swatch below reads live from the CSS variables defined
in `app/globals.css` — if DESIGN.md and globals.css ever disagree, this
page diffs.

> **Reserve strong accent saturation for primary actions, focus indicators,
> and active states.** Use `--primary-soft` for selected backgrounds,
> active pane highlights, hover badges. Use warm surface treatment
> (`--surface-warm`) for featured CTA areas.

## Do / don't

- **Do** use `--primary-soft` for selected-item backgrounds and active pane highlights.
- **Do** preserve panel/surface hierarchy through tone and border contrast before reaching for shadow.
- **Don't** introduce new chroma families without an explicit product decision.
- **Don't** raise accent saturation for ambient decoration.
