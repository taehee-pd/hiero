# Dimensions

Sourced from `/DESIGN.md` §5 "Layout Principles > Concrete dimensions"
and §9 agent prompt example ("ghost icon buttons at 28px with 14px
icons"). These are the canonical pane and chrome sizes — every value
below is a named CSS variable in `app/globals.css` so DS components
can reference them instead of hardcoding magic numbers.

## Studio chrome

| Token | Value | Element |
|---|---|---|
| `--navbar-height` | `40px` | top navbar |
| `--toolbar-height-min` | `36px` | toolbar height — lower bound |
| `--toolbar-height` | `clamp(36px, 2.375rem, 40px)` | toolbar height — responsive |
| `--toolbar-height-max` | `40px` | toolbar height — upper bound |
| `--navpane-width-expanded` | `200px` | NavPane (expanded) |
| `--navpane-width-collapsed` | `56px` | NavPane (collapsed) |
| `--listpane-width` | `260px` | ListPane width |
| `--inspector-width` | `260px` | Inspector width |
| `--panel-padding` | `12px` | internal panel padding |
| `--panel-gap` | `8px` | gap between sibling controls |
| `--section-gap` | `clamp(4px, 0.375rem, 8px)` | gap between sections |

## Form fields

| Token | Value | Use |
|---|---|---|
| `--field-height-sm` | `clamp(26px, 1.75rem, 30px)` | dense field (filters, inline) |
| `--field-height-md` | `clamp(30px, 2rem, 34px)` | default control height |
| `--field-height-lg` | `clamp(34px, 2.25rem, 38px)` | comfortable control height |

## Pills & status

| Token | Value | Use |
|---|---|---|
| `--pill-height-sm` | `20px` | inline status chip |
| `--pill-height-md` | `24px` | default pill / badge |

## Icon buttons

Per `/DESIGN.md` §9: "ghost icon buttons at **28px** with **14px** icons".

| Frame token | Inner token | Frame | Inner |
|---|---|---|---|
| `--button-icon-size-sm` | `--icon-inner-size-sm` | `24px` | `12px` |
| `--button-icon-size-md` | `--icon-inner-size-md` | `28px` | `14px` |
| `--button-icon-size-lg` | `--icon-inner-size-lg` | `32px` | `16px` |

<div style={{ display: 'flex', alignItems: 'center', gap: 16, marginTop: 16 }}>
  {[
    { label: 'sm', frame: 24, inner: 12 },
    { label: 'md (default)', frame: 28, inner: 14 },
    { label: 'lg', frame: 32, inner: 16 },
  ].map(({ label, frame, inner }) => (
    <div key={label} style={{ display: 'grid', gap: 6, alignItems: 'center', justifyItems: 'center' }}>
      <div
        style={{
          width: frame,
          height: frame,
          borderRadius: 8,
          border: '1px solid var(--border)',
          display: 'grid',
          placeItems: 'center',
          background: 'var(--background)',
        }}
      >
        <div
          aria-hidden="true"
          style={{
            width: inner,
            height: inner,
            borderRadius: 2,
            background: 'var(--foreground-tertiary)',
          }}
        />
      </div>
      <code style={{ fontSize: 11, color: 'var(--foreground-secondary)' }}>
        {label} · {frame}px / {inner}px
      </code>
    </div>
  ))}
</div>

## Responsive behavior

- On narrower widths, collapse non-critical panes first (NavPane → ListPane).
- Preserve core authoring canvas and essential edit controls.
- Keep destructive or publish actions visible and explicit.
