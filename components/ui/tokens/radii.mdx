# Radii

Sourced from `/DESIGN.md` §4 "Component Stylings > Buttons" and §9
example prompts. Generous radius is structural — `/DESIGN.md` §8
explicitly bans sharp corners (less than 6px) on interactive elements.

## Token reference

| Token | Value | Where it's used |
|---|---|---|
| `--radius-toolbar-action` | `0.5rem` (8px) | toolbar action buttons, standard text inputs |
| `--radius-input` | `0.5rem` (8px) | input field corners |
| `--radius-search` | `0.625rem` (10px) | search inputs |
| `--radius-panel-nav` | `0.875rem` (14px) | panel navigation items, icon grid tiles |
| `--radius-pill` | `9999px` | full pill — primary CTAs, badges, accent-soft chips |

## Tailwind v4 scale

Tailwind utilities (`rounded-sm`, `rounded`, `rounded-md`, `rounded-lg`,
`rounded-xl`) resolve through these `@theme` aliases. They derive from
the structural `--radius` base (`0.375rem`, 6px).

| Token | Value | Tailwind utility |
|---|---|---|
| `--radius` | `0.375rem` (6px) | `rounded` |
| `--radius-md` | `calc(var(--radius) - 2px)` | `rounded-md` |
| `--radius-lg` | `var(--radius)` | `rounded-lg` |

## Usage rules (DESIGN.md §4 + §9)

- **`9999px` full pill** — primary CTAs, badges, status indicators, accent-soft chips.
- **`0.875rem` / 14px** — panel navigation items, icon grid tiles.
- **`0.625rem` / 10px** — search inputs.
- **`0.5rem` / 8px** — toolbar actions, standard text inputs.
- **Never** less than 6px on interactive elements. §8 guardrail: "sharp corners on interactive elements are banned."
