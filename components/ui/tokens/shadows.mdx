# Shadows

Sourced from `/DESIGN.md` §6 "Depth & Elevation". Every shadow lives
at **sub-0.1 opacity**; many combine both **outward cast AND inward
inset** components to create surfaces that feel present but not heavy.
Dark-mode values compensate with 16–28% opacity since they compete
with a dark canvas.

> Inset half-pixel borders create edges so subtle they are *felt
> rather than seen*.

## Levels

| Level | Token | Use |
|-------|-------|-----|
| 0 Flat | — | Background surfaces, text blocks |
| 0.5 Inset edge | `--shadow-inset-edge` | Panel internal edge definition |
| 1 Outline ring | `--shadow-outline` | Shadow-as-border for cards |
| 1 Subtle lift | `--shadow-sm` | Resting cards, subtle elevation |
| 2 Elevated | `--shadow-md` | Prominent cards, dropdowns |
| 3 Feature lift | `--shadow-lg` | Dialogs, popovers |
| Panel | `--shadow-panel` | Floating panels (color picker, command menu) |
| Stage | `--shadow-stage` | Canvas / preview stage surfaces |
| Error | `--shadow-error` | Destructive surfaces (validation halos) |

## Don't

- Use heavy shadows (>0.12 opacity in light mode). The refined quality requires whisper-level depth.
- Skip the inset-shadow component on panels. Half-pixel inset borders are structural.
