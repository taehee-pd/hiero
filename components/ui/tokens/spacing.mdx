# Spacing

Sourced from `/DESIGN.md` §5 "Layout Principles". Spacing is deliberately
tight — the design system targets medium-dense data tooling. These
values come straight from `app/globals.css` and are visible via CSS
variables on `:root`.

## Panel rhythm tokens (DESIGN.md §5)

| Token | Value | Purpose |
|---|---|---|
| `--panel-padding` | `12px` | internal spacing rhythm inside every panel |
| `--panel-gap` | `8px` | gap between siblings inside a panel |
| `--section-gap` | `clamp(4px, 0.375rem, 8px)` | gap between semantic sections |
| `--section-padding-x` | `clamp(10px, 0.75rem, 14px)` | horizontal padding inside a section |
| `--section-padding-y` | `clamp(8px, 0.625rem, 12px)` | vertical padding inside a section |
| `--field-gap` | `clamp(4px, 0.375rem, 6px)` | gap between adjacent form fields |

## Whitespace philosophy

- **Purposeful breathing room** — ElevenLabs-generous, adapted for density. Each pane is self-contained with clear internal rhythm.
- **Warm emptiness** — Empty states use subtle dotted backgrounds (`.studio-dots`) and muted text rather than harsh blank space.
- **Typography-led rhythm** — Light heading weights create hierarchy without heavy dividers.
