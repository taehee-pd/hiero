# Typography

Sourced from `/DESIGN.md` §3 "Typography Rules". Every size, weight,
line-height, and letter-spacing below is a direct quote from the
authoritative scale in DESIGN.md. No values are invented on this page.

> **Primary UI font:** system sans stack (matching the app). **Display:**
> Geist Sans at weight **450** — the Contour equivalent of ElevenLabs'
> light-weight display approach. Lightness creates intrigue through
> restraint. **Code / technical values:** Geist Mono.

## Principles

- **Restrained weight as identity.** Like ElevenLabs' Waldenburg 300, Contour uses weight **450** (not bold) for display text. The understated weight signals precision and professionalism.
- **Positive letter-spacing on small text.** Labels and captions use `+0.03125rem` tracking for airy readability at small sizes, contrasting with the tighter display tracking.
- **Monospace as ambient.** Geist Mono at relaxed line-height for code values feels unhurried.

## Do / don't

- **Do** keep line lengths short in side panes.
- **Do** prefer consistent casing within a panel.
- **Don't** use oversized marketing-style hero typography inside tool panels.
- **Don't** use bold (700) weights for headings — the lighter weight IS the identity.
