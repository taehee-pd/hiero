# Typography

Sourced from `/DESIGN.md` §3 "Typography Rules". Every size, weight,
line-height, and letter-spacing below is a direct quote from the
authoritative scale in DESIGN.md. No values are invented on this page.

> **Primary UI font:** system sans stack (matching the app). **Display:**
> Geist Sans at weight **450** — the Hiero equivalent of ElevenLabs'
> light-weight display approach. Lightness creates intrigue through
> restraint. **Code / technical values:** Geist Mono.

## Token reference

### Font families

| Token | Resolves to | Use |
|---|---|---|
| `--font-system` | system sans stack | primary UI font (matches the app shell) |
| `--type-family-default` | `--font-geist-sans` | default text family |
| `--type-family-display` | `--font-geist-sans` | display headings |
| `--type-family-mono` | `--font-geist-mono` | code, technical values |

### Font weights

| Token | Value | Use |
|---|---|---|
| `--type-weight-default` | `450` | body text, default UI weight |
| `--type-weight-medium` | `450` | unchanged from default — preserved for semantic intent |
| `--type-weight-strong` | `550` | labels, captions, emphasized inline text |
| `--type-weight-heavy` | `550` | maximum weight — never go heavier |

Tailwind v4 utilities (`font-medium`, `font-semibold`, `font-bold`)
resolve through these `@theme` aliases.

### Size scale

These map 1:1 to Tailwind's `text-{xs,sm,base,lg,xl,2xl}` utilities
via `@theme`. Each size carries paired `--*--line-height` and
`--*--letter-spacing` tokens defined alongside.

| Token | Value | Tailwind utility | Role |
|---|---|---|---|
| `--text-xs` | `0.5625rem` | `text-xs` | caption / metadata |
| `--text-sm` | `0.6875rem` | `text-sm` | label / control |
| `--text-base` | `0.8125rem` | `text-base` | body / UI |
| `--text-lg` | `0.9375rem` | `text-lg` | body large |
| `--text-xl` | `1.5rem` | `text-xl` | section heading |
| `--text-2xl` | `3rem` | `text-2xl` | display hero |

### Legacy `clamp()` aliases

Used directly via `var()` in panel CSS for fluid sizing. Reach for
the size scale above for new code; these stay for compatibility with
existing wire-* panel rules.

| Token | Value |
|---|---|
| `--text-heading` | `clamp(12px, 0.8125rem, 14px)` |
| `--text-body` | `clamp(12px, 0.8125rem, 14px)` |
| `--text-label` | `clamp(10px, 0.6875rem, 12px)` |
| `--text-caption` | `clamp(9px, 0.625rem, 11px)` |

## Principles

- **Restrained weight as identity.** Like ElevenLabs' Waldenburg 300, Hiero uses weight **450** (not bold) for display text. The understated weight signals precision and professionalism.
- **Positive letter-spacing on small text.** Labels and captions use `+0.03125rem` tracking for airy readability at small sizes, contrasting with the tighter display tracking.
- **Monospace as ambient.** Geist Mono at relaxed line-height for code values feels unhurried.

## Do / don't

- **Do** keep line lengths short in side panes.
- **Do** prefer consistent casing within a panel.
- **Don't** use oversized marketing-style hero typography inside tool panels.
- **Don't** use bold (700) weights for headings — the lighter weight IS the identity.
