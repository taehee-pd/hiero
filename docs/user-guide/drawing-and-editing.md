# Drawing and Editing

[Home](./index.md) | [Previous: Editor Workspace](./editor-workspace.md) | [Next: Size Versions and Guides](./size-versions-and-guides.md)

## Selection Tool

Use the selection tool to work with whole layers.

Typical tasks:

- pick a layer from the canvas
- move a layer
- combine or align multiple layers after selecting them

## Point-Editing Tool

Use the point-editing tool when you need precise vector control.

You can:

- select anchor points
- drag anchor points
- move curve handles
- box-select multiple points
- align or distribute selected points
- round corners by adding handle radius
- switch point behavior between corner and smooth styles

## Pen Tool

Use the pen tool to draw new path-based shapes point by point.

Typical workflow:

1. Click to start a new path.
2. Click again to add straight segments.
3. Drag while placing a point to create a curve.
4. Continue until the shape is finished.
5. Close the shape by returning to the start.

## Shape Tool

The shape tool can create:

- rectangle
- ellipse
- polygon
- star
- line

Shape-specific controls appear on the right side when the tool is active. For example, polygons and stars expose side or point counts.

## Styling

When a layer is selected, the right side lets you adjust:

- fill
- stroke
- stroke width
- fill opacity
- stroke opacity
- line caps
- line joins

Color choices can be:

- current text color
- fixed color
- gradient

Both linear and radial gradients are supported.

## Transforms

Each layer can be repositioned and reshaped through transform controls, including:

- horizontal move
- vertical move
- rotation
- horizontal scale
- vertical scale

## Boolean and Masking Tools

When enough path layers are selected, the right side unlocks advanced tools such as:

- shape merging
- clipping masks
- layer alignment
- layer distribution

These are useful for building final icons from several simpler pieces.
