## Layout

The editor is split into three working columns plus a top bar.

## Top Bar

The top bar gives you:

- new project
- open project
- import SVG
- save project
- export the current icon as SVG
- undo and redo
- zoom out, zoom in, and fit view

## Left Side

The left side has three jobs:

- current icon summary
- tool and snapping controls
- either the layer list or the guide manager

### Tool Area

The tool area includes:

- selection tool
- point-editing tool
- pen tool
- shape tool
- snap toggle
- guide visibility toggle

When the shape tool is active, you can also choose the specific shape type.

### Layer List

The layer list shows the drawing order and visibility of the current icon version. Use it to:

- select a layer
- hide or show a layer
- recognize masking relationships

### Guide Manager

When guides are visible, the left panel can switch into guide management. This is where you create, duplicate, edit, and remove reusable guide overlays.

## Center Canvas

The canvas is where you draw and edit. It supports:

- pan and zoom
- direct SVG import by dragging a file onto the canvas
- ruler-based guide creation by dragging out from a ruler
- point boxes and handles when point editing is active
- snap feedback while moving points

## Right Side

The right side changes depending on what is selected. It can show controls for:

- shape drawing options
- layer information
- clipping
- boolean operations
- align and distribute
- fill and stroke styling
- point editing
- transforms

## Canvas Header

Above the canvas, you can switch between size-specific versions of the same icon. This area also lets you add a new size and remove the current one.
