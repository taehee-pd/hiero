## What Hiero Is For

Hiero is a browser-based icon editor for:

- building icons from paths and shapes
- creating multiple size-specific versions of the same icon
- refining anchor points and handles
- applying fills, strokes, gradients, masks, and transforms
- organizing icons into categories
- importing SVG artwork and exporting clean SVG output
