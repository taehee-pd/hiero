# Export to Coniva

Local Figma plugin for exporting the current selection into a Coniva import payload.

## Install in Figma

1. Open Figma desktop.
2. Go to `Plugins` → `Development` → `Import plugin from manifest...`.
3. Choose [manifest.json](/Users/taehee/IconStudio/figma-plugin/export-to-coniva/manifest.json).

## Use

1. Select one or more vector or component nodes.
2. Run `Export to Coniva`.
3. Click `Export selection`.
4. Copy or download the JSON payload.
5. In Coniva, open `Import icon` → `Coniva Plugin` and paste or upload the payload.
