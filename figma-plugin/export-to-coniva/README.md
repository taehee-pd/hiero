# Export to Contour

Local Figma plugin for exporting the current selection into a Contour import payload.

## Install in Figma

1. Open Figma desktop.
2. Go to `Plugins` → `Development` → `Import plugin from manifest...`.
3. Choose [manifest.json](/Users/taehee/Contour/figma-plugin/export-to-contour/manifest.json).

## Use

1. Select one or more vector or component nodes.
2. Run `Export to Contour`.
3. Click `Export selection`.
4. Copy or download the JSON payload.
5. In Contour, open `Import icon` → `Contour Plugin` and paste or upload the payload.
