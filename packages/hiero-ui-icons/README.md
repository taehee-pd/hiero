# @hiero/ui-icons

Hiero's own UI icon set. Authored in the Hiero editor, rendered by the
Hiero runtime, consumed by the Hiero app.

## Usage

```tsx
import { Icon } from '@hiero/ui-icons';

<Icon name="plus" size={16} aria-label="Add icon" />
```

For bundle-optimal direct imports:

```tsx
import { IcPlus } from '@hiero/ui-icons';

<IcPlus size={16} />
```

## Development

```bash
pnpm icons:import   # re-import from lucide-react based on source/manifest.json
pnpm icons:build    # compile icons.json → generated/ + registry.generated.ts
pnpm icons:verify   # build and fail if the output has changed (CI gate)
```

## Layout

```
source/
  manifest.json          # list of icons (edit this to add/remove)
  icons.json             # IconSet JSON (regenerated by icons:import)
generated/               # compiled + per-icon React components (generated)
src/
  index.tsx              # <Icon name="..."> wrapper
  registry.generated.ts  # typed IconName union + name → component map (generated)
```

`source/icons.json` is the source of truth. IndexedDB inside the
editor is a working copy; publishing writes back to the source file.

See `docs_canonical/hiero-ui-icons/DECISIONS.md` for the full design
decisions and `docs_canonical/hiero-ui-icons/INVENTORY.md` for the
audit of current icon usage across the app.

See `docs_canonical/hiero-ui-icons/MIGRATION_PUBLISH_PLAN.md` for the execution plan covering migration and the day-to-day edit/publish loop.
